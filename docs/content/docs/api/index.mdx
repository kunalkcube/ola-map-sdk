`OlaMapsClient` exposes **7 strongly-typed endpoint modules** covering 40 Ola Maps API operations. Every method returns a typed `Promise`, validates coordinates and documented API caps locally, and accepts an optional trailing [`RequestOptions`](/docs/configuration#per-request-options-requestoptions) object.

## Endpoint Matrix

| Module | Methods | Key Capabilities & Local Validation Caps |
| --- | --- | --- |
| [**Places & Geocoding**](/docs/api/places) | 10 methods | Autocomplete, Geocode, Reverse Geocode, Place Details (+ Advanced), Nearby Search (+ Advanced, `limit: 1..50`, `layers`), Text Search, Address Validation, Place Photos |
| [**Routing**](/docs/api/routing) | 6 methods | Turn-by-turn Directions (+ Basic), Distance Matrix (+ Basic), Route Optimizer (max `25` locations), Fleet Planner (Web `FormData` + `Blob`) |
| [**Roads**](/docs/api/roads) | 3 methods | Snap to Road (max `50` points), Nearest Roads (max `100` points), Speed Limits (max `50` points) |
| [**Street View**](/docs/api/street-view) | 3 methods | Bounding-box Coverage, Nearest Image ID, Panorama Metadata & Neighbors |
| [**Geofencing**](/docs/api/geofencing) | 6 methods | Create, Get, Update, Delete, List (paginated), Check Point-in-Geofence Status |
| [**Elevation**](/docs/api/elevation) | 2 methods | Single-point Elevation, Batch Elevation (max `25` locations) |
| [**Tiles & Static Maps**](/docs/api/tiles) | 10 methods | Styles List, Style JSON, Vector TileJSON, Vector `.pbf`, Raster `.png`/`.jpg`, SDF Font Glyphs, Static Map (Center, BBox, Auto; `1..2048px`), 3D Buildings Tileset |

## Shared Conventions Across All Methods

1. **Flexible Coordinates**: Pass `{ lat, lng }`, `{ lat, lon }`, `[lng, lat]`, or `"lat,lng"` strings anywhere a `CoordinateInput` is accepted.
2. **Pipe-Separated Lists**: Methods taking multiple coordinates (`waypoints`, `origins`, `destinations`, `locations`, `points`) accept either an array of `CoordinateInput[]` or a pipe-delimited string (`"12.93,77.61|12.97,77.59"`).
3. **Fail-Fast Validation**: Out-of-range coordinates (`lat` outside `[-90, 90]`, `lng` outside `[-180, 180]`) or exceeded API caps throw `OlaValidationError` immediately without making a network request.
4. **Per-Request Control**: Every method accepts an optional final `requestOptions?: RequestOptions` argument for `signal`, `timeoutMs`, `requestId`, `correlationId`, `headers`, `retries`, and `skipCache`.
